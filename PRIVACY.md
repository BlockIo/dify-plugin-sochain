# Privacy Policy

The SoChain plugin does not collect, store or log any user data itself.

When a tool runs, the plugin sends the tool inputs (network, address, transaction ID, block height or hash, page number) to the SoChain API at `https://sochain.com/api/v3` over HTTPS, with your SoChain API key if you set one, and returns the API response to Dify. No other data is sent and no other third party is contacted.

If you set an API key, Dify stores it as an encrypted secret credential; the plugin does not store it.

How SoChain handles the requests it receives is described in its privacy policy at https://sochain.com/privacy. Questions: support@sochain.com.
